# Real-Time Vehicle Detection with OpenCV

A computer-vision project that detects vehicles in video frames and tracks objects of interest across the sequence.

## Objective

Explore vehicle detection in video streams and the challenges of identifying and tracking vehicles from moving-camera footage.

## Core workflow

1. Read video frames.
2. Apply vehicle-detection logic.
3. Identify detected vehicles in each frame.
4. Track detections across consecutive frames.

## Context

Vehicle detection can support traffic analysis and road-safety research. Real-world deployment requires evaluation across lighting, camera motion, occlusion, weather and traffic density.

- OpenCV
